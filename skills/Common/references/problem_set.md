# 练习通用规则

每次两套，具体题型数量由科目定义。两套内、与同科目同模块历史间都不得重复；只换数值、变量、语序、背景或题型仍算重复。重新设计条件组合、提问目标或解题结构，不能靠超纲或降低难度避重。

顺序固定：`## 第一套 题目` → `## 第二套 题目` → `## 答案与解析` → `## 第一套 详细解析` → `## 第二套 详细解析`。必须先列完所有题目，再写全部答案，不泄露提示或思路。每套单独从 1 编号，解析与本套逐题对应。

题型标题用 `### 一、填空题` 等，题号用 `#### 第 X 题`。解析每题开头为独立段落 `**【难度：中等】**`（或简单、困难）。选择题须给 A、B、C、D 四项且唯一正确；解析先给正确选项，再说明理由。

答案完整自洽，明确假设、关键定理、主要步骤与结论；必要时讨论参数、边界或分支。改编后必须重新计算，不能沿用失配答案。解析强调关键思路与适用条件，不为凑字堆叙述。改编题只在解析末尾标“改编”；原创题可写“原创模拟”，不逐题打印原网址、年份或出处。

跨次历史在 `local_practice/`，不同科目隔离；更换 AI 或输出格式仍使用同一模块历史。工具检查题干、数值/字母变体与文本高度相似，不能声称保证数学语义绝对无重复。最多生成三轮，不合格则报告，保留已生成正文供检查。

独立运行 `python skills/Common/scripts/check_practice.py 练习.md --chapter "模块名"` 检查，加 `--record` 登记。排版执行 `formatting.md`，两套与答案标题居中；解析中的重点文字加粗，难度标签不缩进。
