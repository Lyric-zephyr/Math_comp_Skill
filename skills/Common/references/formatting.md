# 统一排版

所有科目、所有 AI、所有运行方式共用 `../assets/` 和 `../scripts/` 中的导出模板。

正文宋体四号（14pt），文字自然段首行缩进两个汉字；段首不手动加空格。所有标题黑体加粗；总标题居中、小二，`##` 大标题三号（16pt），`###`、`####` 小标题四号。目录只列 `##`，不手写目录。

独立公式用 `$$ ... $$`，前后空行、居中。重点公式用 `\boxed{...}`，模板统一渲染红框；通常每个模块选择 6–8 个，以重要性为准，不重复框选同一公式。重要定义、条件和语句在原位置用 `**...**` 加粗，不另开重点复述区。

公式使用 KaTeX 支持的语法，花括号与数学定界符完整配对，分式写全 `\frac{分子}{分母}`，数学填空写 `\underline{\qquad\qquad}`，不使用连续下划线。

练习中两套题目、答案与解析、各套解析标题均用 `##`，居中且大于题号。题号用 `#### 第 X 题`。难度标签独立成段、左对齐、不缩进；标题、公式、表格也不缩进。解析按需要用 `##### 思路`、`##### 推导` 等小标题，并加粗关键步骤，避免整段加粗。
