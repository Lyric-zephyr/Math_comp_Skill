# 统一排版

所有科目、所有 AI、所有运行方式共用 `../assets/` 和 `../scripts/` 中的导出模板。

正文宋体四号（14pt），少量重点用 `**...**` 标记，由模板显示为同字号、中等字重的黑体，与普通宋体明显区分；标题使用更粗的黑体。文字自然段首行缩进两个汉字；段首不手动加空格。所有标题黑体加粗；总标题居中、小二，`##` 大标题三号（16pt），`###`、`####` 小标题四号。目录只列 `##`，不手写目录。

正文统一 2.0 倍行距，段前、段后不额外留白，换段处与普通换行保持同样间距。Markdown 自然段仍用空行分隔，视觉间距由模板控制。

易错总结的条目统一为普通段落 `1.标题：正文`，条目不用 Markdown 标题，标题不加粗，正文可像知识梳理一样加粗少量关键词语；知识梳理正文保留少量清晰可辨的加粗词语或短句。

只使用 Markdown 标题与段落，不输出 `<div align="center">`、`<center>` 等 HTML 排版标签；居中由模板完成。选择题 A、B、C、D 每项独立成段、两项间空一行，标号写作 `A．`、`B．`、`C．`、`D．`，四项均首行缩进两个汉字，不用列表、表格或软换行排列选项。

独立公式用 `$$ ... $$`，前后空行、居中。重点公式用 `\boxed{...}`，模板统一渲染红框；通常每个模块选择 6–8 个，以重要性为准，不重复框选同一公式。正文仅强调少量关键术语、限制条件或结论短语，必要时可标一个短句；知识小节通常 1 处，极短或纯公式小节可不标，不连续加粗多个句子或整段，不另开重点复述区。

公式使用 KaTeX 支持的语法，花括号与数学定界符完整配对，分式写全 `\frac{分子}{分母}`，数学填空写 `\underline{\qquad\qquad}`，不使用连续下划线。

多个并列公式不挤在行内正文中：先单独写“常用极限”等文字标签，再另起公式行。每一行整体的中心须与正文版心重合，不能仅把整块公式居中而让内部各行靠左。每行 1–2 个，短式可并排，长式单独一行；逐条用 `$$ ... $$`，模板按实际宽度决定是否两条并排，并在同一行的两式之间自动加逗号，不留大块空白。独立公式清单不用 `aligned` 或 `array` 排成左对齐的多行块；真正的等式推导仍可按等号对齐。单个短公式、变量或条件仍可正常行内使用。

公式保持统一字号，禁止用 `\small`、`\scriptsize`、缩放或缩小字号来适配宽度。长等式用 `aligned` 等环境在等号、加减号或逻辑分隔处换行；表格内只保留能以原字号放下的简式，长式移到表格外。

并列出现多个公式时，先单独写文字标签，再逐条另起独立公式行，每行整体对准正文版心，不用aligned或array把公式清单排成左对齐块；每行1–2个，同行两式之间由模板加逗号，长式单独一行；公式用$$居中并空行分隔，超宽用aligned断行，禁止缩小字号或把多条公式塞进行内正文。正文首行缩进由模板处理。

练习中两套题目、答案与解析、各套解析标题均用 `##`，居中且大于题号。题号用 `#### 第 X 题`。难度标签独立成段、左对齐、不缩进；标题、公式、表格也不缩进。解析按需要用 `##### 思路`、`##### 推导` 等小标题，并加粗关键步骤，避免整段加粗。
