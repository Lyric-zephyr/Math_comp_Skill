# 数学竞赛

读取同级 [Common](../Common/SKILL.md) 的共同排版、资料规则与当前任务规则，再读本目录 `references/modules/` 的对应模块边界。资料库使用 [Assistant_course](https://github.com/Lyric-zephyr/Assistant_course) 中的 `Mathematics_Competition`，默认按需在线读取，不混入复变函数题。

## 总结模式

采用共同的“知识梳理 → 易错总结”，不重复基础与核心；易错每个普通模块 7–10 条。用户 PDF → GitHub Assistant_course/Course/Mathematics_Competition → 自身知识。单独综合模块完整覆盖前六模块；全部模块仅生成前六份。

## 练习模式

读取 [数竞题型与难度](references/problem_set.md)。全部模块生成七份，单独综合需跨章组合。排版、先题后答、改编说明与避重遵守共同规则。
