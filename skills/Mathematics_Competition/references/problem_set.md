# 数学竞赛题型与难度

每次两套，每套 5 道填空、5 道解答，共 20 题。每套第 1–5 题填空，第 6–10 题解答；题型标题 `### 一、填空题`、`### 二、解答题`。

先在线读取 GitHub Assistant_course/Practice/Mathematics_Competition，缺少相关正文时再用全国大学生数学竞赛官网与已有开放参考题库。非数 A 为主要难度与范围基准，非数 B、数学 A 仅选当前模块覆盖且非数 A 不超纲的部分。旧届不冒称已分 A/B，未读原文不冒称真题。访问方式见 [来源规则](source_access.md)。

普通习题按六个知识模块检索，历届真题保留完整原卷。章节训练也可参考真题中的相关题目改编，选择当前模块覆盖的思路与条件，避免将整卷或其他章节题混入。关联答案仅供核对原题号，改编题全部重新求解。

每套最多 1 道相对基础题，至少 5 道中等、4 道困难；第 9、10 题达到非数 A 压轴训练强度，需要构造、分情况或至少两层推理，不能只加大运算量。填空不冒充长篇证明。单模块严守边界，综合模块跨章配合。

本次20题之间、与同模块历史题目之间均不得重复。不能只换数值、字母、语序或背景；需改变条件组合、提问目标或解题结构，同时保持模块范围和非数 A 竞赛难度。

改编只需在解析末尾写“改编”，不逐题标来源；题干改变后全部重算答案。两套先题后答、题号重置、难度标签、红框与加粗、历史避重均使用 Common 规则。
