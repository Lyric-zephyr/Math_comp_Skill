# 知识点总结规则

## 核心要求
1. 章节隔离：只能总结用户指定模块的内容，严禁越界。
2. 篇幅均衡：总字数控制在 1500-2000 字左右。
3. 功能独立：只总结知识点、公式、定理与适用条件，不检索或引用竞赛试卷、开放题库，不输出模拟题、答案或逐题解析。
4. 教材可选：优先参考用户提供的相关教材；教材缺失、为空、不相关或不足以覆盖本模块时，使用 AI 自身的高等数学知识完成总结。不能因缺少教材而拒绝生成或要求用户上传资料，也不能编造教材、页码或引用来源。

## 格式与排版规范（严格执行）
1. **统一输出 Markdown 格式**（包含 LaTeX 公式）。
2. **目录**：无需手写目录，导出程序仅收录 `##` 大标题；`###`、`####` 小标题只出现在正文中。
3. **公式居中**：所有的独立公式必须使用 `$$ ... $$` 包裹，以保证渲染时居中。
4. **核心公式红框高亮**：对于该章节最核心、必考、竞赛常出的公式（每个模块选 4-5 个），必须使用 `$$\boxed{公式内容}$$` 包裹，导出程序会自动将方框显示为红色。
5. **结构顺序**：严格按以下三个大标题组织内容：
   - `## 一、基础公式`
   - `## 二、核心定理`
   - `## 三、竞赛拓展结论`（所有拓展、冷门结论只能放在这一节）
6. **正文重点加粗**：每个小节必须在正文中用 `**重点文字**` 标出 1-3 处关键定义、结论、适用条件或易错提醒。定义段至少加粗定义的关键语句，定理段至少加粗其条件或结论；加粗应嵌在正文句子中，不要仅加粗标题，也不要整段加粗。
7. **编号小标题**：每个 `##` 大标题下面必须有 `### 1. 知识点名称`、`### 2. 知识点名称` 等编号小标题，每个大标题下从 1 重新编号，不能将“极限的含义”等标题写成普通段落。每个独立知识点单列小标题；较长内容用 `#### 适用条件`、`#### 解题方法`、`#### 易错提醒` 等进一步分段。所有小标题只在正文展示，不进入目录。
8. **段落缩进**：正文首行缩进两个汉字，由模板实现；Markdown 段首不要手动添加空格或全角空格，以免被识别成代码或重复缩进。标题、公式、列表和表格不缩进。

## 结构与加粗示例
```markdown
## 一、基础公式

### 1. 极限的含义

数列收敛到 $A$ 的关键是：**对任意 $\varepsilon>0$，都存在正整数 $N$**，使 $n>N$ 时有 $|a_n-A|<\varepsilon$。

函数在一点的极限只考察附近的变化，**不要求函数在该点有定义**。

### 2. 连续的定义

连续要求**函数值存在，且该点极限等于函数值**。
```

输出前逐项检查：每个大标题下有编号小标题；每个小节的正文有重点加粗；小标题不写入目录。

## 样式声明（供底层排版参考）
- 全文正文统一宋体，字号四号（14pt），首行缩进两个汉字，白底黑字。
- 所有级别标题一律黑体加粗；总标题小二、居中；“一、基础公式”等二级大标题三号（16pt）；“1. 极限的含义”等三级、四级小标题四号（14pt），只在正文展示，字号小于大标题。
