# 复变函数练习规则

每次两套，每套 14 题：5 填空（1–5）、5 单项选择（6–10）、4 解答（11–14），总共 28 题。每套用 `### 一、填空题`、`### 二、选择题`、`### 三、解答题`，第二套重新从 1 编号。解析每套也从 1 到 14，与题干匹配。

优先在线读取 GitHub Assistant_course/Practice/Complex_Analysis 相关题目及答案；其次 MIT OCW 18.04 的公开习题、模拟卷与解答。课程资料只补充定义和条件，不能把已有网址当成已读取题目。MIT 18.04 不覆盖的拉普拉斯等内容依本地库或原创，不强行套用不相关素材。

普通习题按七个学习模块查找；历年期中、期末真题保留整套，也可从中选取本模块题目改编，综合题只采用当前范围可覆盖的部分。答案与题干须核对原题号，题设改变后重新计算。

难度以用户课程资料、习题册和期末卷为基准，兼顾常规题和综合推理；每套至少 3 道困难题，最后 2 道大题包含多步推理、条件/参数讨论或方法组合，禁止用一步代入凑压轴。选择题干扰项反映真实误区且唯一正确，不设置无定义或歧义选项。

分支、收敛域、积分方向、曲线内外奇点、变换归一化必须明确。计算题给结果与步骤，证明题论证完整。改编只标“改编”，不写逐题出处；按 Common 规则先列全两套题目再给两套答案，排版、难度标签、加粗和避重与数竞相同。
